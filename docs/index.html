Guide

使用教程

隔离应用

用另一个端口和独立数据目录启动副本，例如 DATA_DIR=/tmp/demo-data python -m myapp --port 8799。把数据目录写进 story 的 wipe，每次录制都从相同状态开始。

写 story

复制 story_template.py，填 TITLE、CHAPTERS、launch()，然后用 d.say、d.click、d.zoom、d.mark 写分镜。一条字幕一个意思，字幕同时就是解说稿。

试录、正式录制、检查

demo_record.py --quick 快速抓选择器和状态问题；正式录制后运行 demo_render.py --check，按输出修正，直到没有 注意：。

渲染与配音

demo_render.py --out 生成无声成片；demo_voice.py 加普通话解说。配音检查以 没有发现问题 结尾才算完成。

修改与重跑

改字幕、标注、镜头：重录 → 重渲染 → 重配音。只改配音设置：demo_voice.py build。某一句念错：删掉它的 take，再 demo_voice.py takes N。

How

How it works

01

Record

Playwright drives headless Chromium through the story: clicks, typing, scrolling, waiting. The app runs as a throwaway instance with its own port and data, never the live service.

02

Render

Every frame is composited at 1920×1080, 60 fps: camera moves, element outlines, numbered steps, original-text highlights, chapters and captions.

03

Narrate & verify

Local Qwen3-TTS fits each line to its caption. Whisper re-listens, CAM++ checks the voice, packet hashes prove the picture is untouched.

  • Camera zooms
  • Text highlights
  • Numbered steps
  • Fast-forward waits
  • Off-page notes
  • Numeric checks

Guide

Tutorial

Isolate the app

Start a copy on another port with its own data directory, for example DATA_DIR=/tmp/demo-data python -m myapp --port 8799. Put that directory in the story's wipe list so every take starts from the same state.

Write the story

Copy story_template.py, set TITLE, CHAPTERS and launch(), then direct with d.say, d.click, d.zoom and d.mark. One idea per caption; captions are also the narration script.

Trial, record, check

demo_record.py --quick catches bad selectors and page state fast. Record for real, then run demo_render.py --check and fix until it prints no 注意： problems.

Render and narrate

demo_render.py --out writes the silent video; demo_voice.py adds the Mandarin narration. The narration is done only when its check ends with 没有发现问题.

Iterate

Captions, marks or camera: re-record, re-render, re-narrate. Narration settings only: demo_voice.py build. One bad line: delete its takes, then demo_voice.py takes N.
